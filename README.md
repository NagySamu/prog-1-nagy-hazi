# A program használata:
A program indítás után egy .txt kiterjesztásű file nevét várja a felhasználótól a standard inputon. A file-nak egy mappában kell lennie a program forráskódjaival.
A file-ban lévő szöveget a program egy logikai függvényként fogja értelmezni.
A következő jeleket lehet a függvény megadására használni: & (és művelet), | (vagy művelet), ! (tagadás), természtesen a kifejezés szabadon zárójelezhető.
Az engedélyezett változók olyan karakterek amelyek nem vesznek részt a függvény kiértékelésében. A fenieken kívül tilos #-et tenni a bemeneti file-ba.
A függvényre, hogy érvényes legyen igaznak kell lennie a matemaika szabályainak, úgy mint minden zárójelet be kell zárni, és a & valamit a | csak két változó vagy zárójel között állhatnak. A ! után mindenképpen változónak vagy zárójelnek kell következnie.
Ezután a prgram kiértékeli a függvényt és az általa megnevezett kimeneti file-ba beleírja az igazságtáblázatát.
